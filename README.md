# 1만 원의 경로 — 전장의 병원은 안전한가

INTERACTIVE DESIGN 수업 과제 (class11: 내 프로젝트에 기능 1개 구현하기)

- 사이트: https://kyo-vcd.github.io/first/
- 기획: 후원금 1만 원이 전장의 병원에 닿기까지, 그리고 그 병원이 공격받을 때 일어나는 일을 8개 장면의 스크롤 스토리로 보여준다.
- 시안: `docs/ref/design_v2.pdf`

## 장면과 인터랙션

| 장면 | 내용 | 사용자 행동 → 화면 변화 |
| --- | --- | --- |
| 01 1만 원의 경로 | 후원금이 86 · 10 · 4로 나뉨 | 금액 슬라이더 · 후원 **클릭** → 동전 낙하, 스크롤 → 분배 · 결과 |
| 02 화폐에서 생명으로 | 8,600원이 구호 키트가 됨 | 키트 만들기 **클릭** → 동전이 물품으로, 스크롤 → 상자에 담김 |
| 03 최후의 안전지대 | 전장의 병원과 제네바협약 | 스크롤 → 보호 구역 · 불 켜짐 · 협약 카드 |
| 04 하루 10번 | 하루 의료 공격 지도 | **스크롤 = 시각** (00:00→24:00) → 공격 지점 · 건수, 3,623건 |
| 05 보호 좌표 = 공습 좌표 | 통보한 좌표가 조준점이 됨 | 두 시점 **클릭 전환**, 스크롤 → 조준경 잠금 · 81% |
| 06 쿤두즈, 2015.10.03 | 외상센터 공습 1시간 | **스크롤 = 시각** (02:00→03:15) → 화재 · 기록 · 붕괴 · 사망 42명 |
| 07 멈춘 수술실 | 비상등 · 심전도 · 불타는 키트 | 스크롤 → 암전 · 심전도 정지 · 키트 소실 |
| 08 꺼진 불빛 | 반경 50km의 생존 기반 | 반경 **드래그** → 불빛이 꺼짐, 서명 **클릭** |

장면별 명세(부모 · 자식 요소, 실행 조건, 유지 조건): `docs/scenes/S01.md` ~ `S08.md` · 강의 내용 대응: [docs/assignment.md](docs/assignment.md)
