## 장면

| 장면 | 사용자 행동 → 화면 변화 |
| --- | --- |
| 01 1만 원의 경로 | 금액 선택 · 후원 클릭 → 동전이 86 · 10 · 4로 나뉨 |
| 02 화폐에서 생명으로 | 키트 만들기 클릭 → 동전이 구호 물품으로, 스크롤 → 상자에 담김 |
| 03 최후의 안전지대 | 스크롤 → 보호 구역 · 불 켜짐 · 제네바협약 카드 |
| 04 하루 10번 | 스크롤 = 하루의 시각 → 공격 지점 · 건수, 연간 3,623건 |
| 05 보호 좌표 = 공습 좌표 | 시점 전환 클릭, 스크롤 → 조준경 잠금 · 81% |
| 06 쿤두즈, 2015.10.03 | 스크롤 = 공습 시각 → 화재 · 기록 · 붕괴 · 사망 42명 |
| 07 멈춘 수술실 | 스크롤 → 비상등 · 심전도 정지 · 불타는 키트 |
| 08 꺼진 불빛 | 반경 드래그 → 마을 불빛이 꺼짐, 서명 클릭 |
