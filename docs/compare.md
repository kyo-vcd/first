# 구성 비교 (현재 / 개선1 / 개선2)

상단 플로팅 영역에서 S01 구성을 바꿔 가며 비교한다. 주소의 `?v=` 값으로 열리므로 링크로 공유할 수 있다.

| 구성 | 주소 | 내용 |
| --- | --- | --- |
| 현재 | `/` | 처음 구성. 후원하기를 누르면 동전이 수조로 바로 떨어진다. |
| 개선1 | `/?v=1` | **핀 분배**: 수조 위 핀 판을 거쳐 동전이 가운데에서 쏟아져 핀에 튕기며 86 · 10 · 4로 갈라진다 (`scene.pdf` "핀을 튕기며 쏟아져 내리고"). 핀에 부딪히면 금빛으로 반짝인다. 분배 확인(STATE 03)부터 핀은 사라진다. **수치 표기**: "86 · 10 · 4% 비율은 기획안 기준 예시 수치" 문구. |
| 개선2 | `/?v=2` | 개선1 + **레버 후원**(아래로 끝까지 당기면 후원, 클릭·Enter도 가능, 1300px 미만은 버튼) · **상태 진행 표시**(01 금액 설정 ~ 다음 장면, 지금 상태 안의 스크롤 진행만큼 막대가 참) · **수조별 금액 미리보기**(슬라이더를 움직이면 8,600원 · 1,000원 · 400원이 바로 바뀜). |

## 구현 위치

- `public/js/compare.js`: `?v=` 를 읽어 `<html data-variant>` 와 `Story.variant` 를 정하고, 플로팅 버튼을 연결한다. `<head>`에서 불러와 화면이 그려지기 전에 적용한다.
- `public/index.html` `.compare`: 플로팅 영역 마크업.
- `public/css/style.css`: 플로팅 영역 스타일, `--top-space`(헤더 + 비교 영역 높이).
- `public/css/scenes/s01.css` 맨 아래 "구성 비교" 블록: `[data-variant]` 별 스타일.
- `public/js/scenes/s01.js`: `FEATURE` 플래그(`pins`, `lever`, `states`, `amounts`)로 기능을 켠다.

## 비교가 끝나면

1. 고른 구성의 기능을 기본으로 만든다 (`FEATURE` 를 고정값으로, CSS 의 `[data-variant]` 조건 제거).
2. `index.html` 의 `.compare` 와 `<script src="js/compare.js">`, `js/compare.js` 를 지운다.
3. `style.css` 의 구성 비교 블록과 `:root[data-variant]` 의 `--top-space` 를 지운다.
