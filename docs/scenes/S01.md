# SCENE 01 — 1만 원의 경로 (후원금 흐름)

기획: `docs/ref/scene.pdf` 2쪽 · 구현: `public/css/scenes/s01.css`, `public/js/scenes/s01.js`

## 적용 범위

```
.scene-01                  ← 스크롤 기준 부모 (250vh, 터치 화면 420vh, 진행률 0~1)
└─ .sticky-screen          ← 화면에 고정되는 영역
   ├─ .s01-headlines       ← 제목 3개가 같은 자리에서 교체
   │   ├─ .s01-title--ask
   │   ├─ .s01-title--split
   │   └─ .s01-title--result
   ├─ .s01-control         ← 후원 금액 슬라이더 + 후원하기 버튼
   ├─ .s01-stage           ← 수조 3개
   │   └─ .s01-tank (--field 86% / --fund 10% / --ops 4%)
   │       ├─ .s01-tank-box    수조 틀
   │       ├─ .s01-coins       동전을 그리는 canvas
   │       └─ .s01-tank-badge  금액 배지 (86% 수조만)
   └─ .s01-next            ← 다음 장면으로 잇는 질문
```

## 상태 변화

방식: **상태 단계형** (스크롤 트리거 + 시간 고정 전환, class11 21쪽 Replace · 38쪽 화면 진입형)

스크롤 진행률은 상태 번호만 정한다. 경계를 넘으면 `.scene-01`에 `is-step-N` 클래스가 누적으로 붙고,
보이는 변화는 CSS `transition`이 항상 같은 시간(0.45~0.9초)으로 재생한다. 스크롤 속도와 상관없이 같은 속도로 바뀐다.

| step | 진행률 | 상태 | 변화 (순서대로) |
| --- | --- | --- | --- |
| 0 | 0 ~ 0.15 | 01 후원 금액 설정 · 02 코인 드롭 | 슬라이더로 금액 선택, 후원하기 → 동전이 86 : 10 : 4로 낙하·누적 (1.6초) |
| 1 | 0.15 ~ 0.40 | 03 분배 확인 | 컨트롤·첫 제목 퇴장 → 제목·수조가 빈자리 채움, 86% 금빛·10%·4% 회색 → 둘째 제목 등장(0.35초 뒤) → 비율·배지 |
| 2 | 0.40 ~ 0.65 | 04 결과 확인 | 둘째 제목·옆 수조 퇴장 → 86% 수조가 가운데로(0.3초 뒤) → 결과 제목(0.55초 뒤) |
| 3 | 0.65 ~ 0.90 | 다음 장면 연결 | 수조가 아래로 물러나며 어두워짐 → 질문 등장(0.4초 뒤) |
| 4 | 0.90 ~ 1 | 장면 끝 | 화면 전체가 어두워짐 (`.scene-curtain`) |

- 상태가 연달아 넘어갈 때는 한 칸씩, 최소 0.5초 간격으로 넘어간다 (`STEP_GAP_MS`). 빠르게 스크롤해도 전환이 순서대로 재생되고 중간에 끊기지 않는다.
- 터치 화면: 한 번 쓸면 다음 상태에서 멈춘다 (상태마다 `.snap-point` + CSS scroll-snap). 손가락 한 번에 움직이는 거리가 길어 상태 사이를 화면 80% 정도로 넓혔다 (`--scene-length: 420vh`).
- 모바일 주소창: 진행률은 주소창과 무관한 높이(100lvh)로 계산하고, 고정 화면도 100lvh로 잡아 배경·바닥이 화면 끝까지 닿는다. 내용은 아래 여백에 `--toolbar`(주소창 높이)를 더해 주소창이 보여도 가려지지 않는다.
- 스크롤 구간은 상태마다 휠 3~4칸(약 35~40vh)이 되도록 잡는다. 전환은 1초 안에 끝나므로 구간이 길면 아무 변화 없이 스크롤만 하는 구간이 생긴다.
- 사라지는 요소가 먼저, 나타나는 요소는 `transition-delay`로 뒤에 온다. 같은 자리에서 겹쳐 보이지 않는다.
- 위로 스크롤하면 이전 상태 클래스로 돌아가고, 기본 규칙의 delay가 쓰여 순서가 거꾸로 재생된다.
- 버튼을 누르지 않고 step 1에 들어오면 기본 금액으로 동전을 빠르게(0.7초) 떨어뜨린다.
- 동전 색 전환(canvas)은 CSS로 할 수 없어 JS가 같은 시간(0.7초)으로 재생한다.
- 금액이 클수록 동전 수(100~280개)와 쌓이는 높이가 커진다.
- `prefers-reduced-motion`이면 낙하와 전환 없이 바로 바뀐다.

## 유지 조건

- 다른 장면의 스타일과 스크립트를 건드리지 않는다. 클래스는 모두 `s01-` 접두어.
- 외부 라이브러리 없이 HTML·CSS·JavaScript만 쓴다.

- 분배 확인: 86% 수조 뒤 금빛이 밝아지고, 10% · 4% 동전은 어두운 갈색, 비율 숫자는 크고 거친 붉은 글자
- 결과 확인: 비율 숫자 없이 86% 수조만 가운데
