# SCENE 01 — 1만 원의 경로 (후원금 흐름)

기획: `docs/ref/scene.pdf` 2쪽 · 구현: `public/css/scenes/s01.css`, `public/js/scenes/s01.js`

## 적용 범위

```
.scene-01                  ← 스크롤 기준 부모 (400vh, 진행률 0~1)
└─ .sticky-screen          ← 화면에 고정되는 영역
   ├─ .s01-headlines       ← 제목 3개가 같은 자리에서 교체
   │   ├─ .s01-title--ask
   │   ├─ .s01-title--split
   │   └─ .s01-title--result
   ├─ .s01-control         ← 후원 금액 슬라이더 + 후원하기 버튼
   ├─ .s01-stage           ← 수조 3개
   │   └─ .s01-tank (--field 86% / --fund 10% / --ops 4%)
   │       ├─ .s01-tank-box    수조 틀
   │       ├─ .s01-coins       동전을 그리는 canvas
   │       └─ .s01-tank-badge  금액 배지 (86% 수조만)
   └─ .s01-next            ← 다음 장면으로 잇는 질문
```

## 상태 변화

| 상태 | 실행 조건 | 시작 상태 | 종료 상태 | 변화 방식 |
| --- | --- | --- | --- | --- |
| 01 후원 금액 설정 | 슬라이더 조작 | 빈 수조 3개, 10,000원 | 선택한 금액 (10,000~100,000원) | 즉시 |
| 02 코인 드롭·누적 | 후원하기 클릭 | 빈 수조 | 동전이 86 : 10 : 4로 쌓임 | 중력 낙하 + 튕김 (1.6초) |
| 컨트롤 정리 | 스크롤 0.10~0.20 | 후원 컨트롤 표시 | 컨트롤 사라짐, 제목·수조가 빈자리를 나눠 채움 | 스크롤 연동 |
| 03 분배 확인 | 스크롤 0.22~0.48 | 모든 동전 금색 | 첫 제목이 빠진 **뒤** 둘째 제목 등장(0.32~), 86% 금빛 강조, 10%·4% 회색, 배지 | 스크롤 연동 |
| 04 결과 확인 | 스크롤 0.52~0.70 | 수조 3개 | 옆 수조가 **먼저** 사라지고(0.52~0.58) 86% 수조가 가운데로(0.57~0.70), 결과 제목 | 스크롤 연동 |
| 다음 장면 연결 | 스크롤 0.78~0.88 | 결과 화면 | 수조가 아래로 빠지며 어두워지고 질문이 가운데 등장 | 스크롤 연동 |
| 장면 끝 | 스크롤 0.93~1.00 | 질문 화면 | 화면 전체가 어두워짐 (`.scene-curtain`) | 스크롤 연동 |

- 사라지는 요소와 나타나는 요소의 구간을 겹치지 않게 나눈다. 같은 자리에서 반투명하게 겹쳐 보이지 않도록.
- 화면에 쓰는 진행률은 `js/script.js`가 실제 스크롤 값을 매 프레임 14%씩 따라가도록 보간한다. 휠 한 칸에도 변화가 끊기지 않는다.
- 버튼을 누르지 않고 0.08을 지나면 기본 금액으로 동전을 빠르게(0.7초) 떨어뜨린다.
- 위로 스크롤하면 03·04 변화가 그대로 되돌아간다.
- 금액이 클수록 동전 수(100~280개)와 쌓이는 높이가 커진다.
- `prefers-reduced-motion`이면 낙하 없이 바로 채운다.

## 유지 조건

- 다른 장면의 스타일과 스크립트를 건드리지 않는다. 클래스는 모두 `s01-` 접두어.
- 외부 라이브러리 없이 HTML·CSS·JavaScript만 쓴다.
