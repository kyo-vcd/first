# SCENE 04 — 하루 10번 (의료 공격 지도)

시안: `docs/ref/design_v2.pdf` 13–16쪽 · 구현: `css/scenes/s04.css`, `js/scenes/s04.js` · 이미지: `images/s04/`

| 항목 | 내용 |
| --- | --- |
| 프로젝트 범위 | `.scene-04` 블록, `css/scenes/s04.css`, `js/scenes/s04.js` |
| 부모 영역 | `.scene-04` (460vh, 터치 화면 520vh) › `.sticky-screen` |
| 변경 요소 | `.s04-timeline`(00:00–24:00 철조망 타임라인 + 시각 핀), `.s04-map`(점 세계 지도), `.s04-hit`(공격 지점 10개), `.s04-tag`(시각 · 장소 꼬리표), `.s04-count`(오늘의 의료 공격 N건), `.s04-year`(3,623건 패널) |
| 실행 조건 | **스크롤 연동형**: 진행률 0–0.7 구간이 하루 00:00–24:00. 시간이 공격 시각을 지나면 그 지점이 터지고 건수가 1씩 오른다. 위로 스크롤하면 시간과 건수가 되돌아간다 |
| 유지 · 검증 | 다른 장면 유지. 수치 출처: Safeguarding Health in Conflict Coalition (2025) |

| 진행률 | 화면 변화 |
| --- | --- |
| 0 – 0.05 | "오늘 하루, 병원은 몇 번 공격받을까요?" 0건 |
| 0.05 – 0.7 | 시간이 흐르며 공격 10건 (지점 펄스 + 꼬리표, 건수 증가) → 제목 "하루 평균 **10번**, 병원이 공격받습니다" |
| 0.7 – 1 (단계) | 지도가 어두워지고 "하루 10건 → 1년" **3,623건** 숫자가 0부터 올라간다 → "이 수많은 공격은 전쟁 중 **우발적 사고**였을까요?" |

모션: 붉은 동심원 펄스(반복), 꼬리표 등장, 타임라인 진행 막대, 숫자 카운트업, 지점 사이 미세한 깜빡임.
