# SCENE 08 — 꺼진 불빛 (영향 반경과 서명)

시안: `docs/ref/design_v2.pdf` 29–32쪽 · 구현: `css/scenes/s08.css`, `js/scenes/s08.js` · 이미지: `images/s08/`

| 항목 | 내용 |
| --- | --- |
| 프로젝트 범위 | `.scene-08` 블록, `css/scenes/s08.css`, `js/scenes/s08.js` |
| 부모 영역 | `.scene-08` (100vh 드래그 구간 + 결말) › `.sticky-screen` |
| 변경 요소 | `.s08-map`(밤 지도), `.s08-lights`(마을 불빛 canvas), `.s08-hole`(어둠 원), `.s08-radius`(영향 반경 0–50km 슬라이더), `.s08-count`(불 꺼진 마을 N곳), `.s08-stats`(22,000+ · 5,900+ 취소선), `.s08-end`(1만 원의 온기 · 서명 버튼) |
| 실행 조건 | **드래그**: 반경 슬라이더를 끄는 만큼 어둠 원이 커지고 그 안의 불빛이 하나씩 꺼지며 숫자가 오른다. 50km에 닿으면 "반경 50km, **불이 꺼졌다**" → 통계에 취소선이 그어짐. **클릭**: "의료 시설 보호 촉구 서명하기" → 서명 완료 상태(서명 수 +1, 동전이 빛남) |
| 유지 · 검증 | 서명은 화면 안 연출만 (외부 전송 없음). 다른 장면 유지 |

| 상태 | 화면 변화 |
| --- | --- |
| 반경 0km | "단 하나의 병원이 사라졌을 때", 금빛 점 = 이 병원에 기대던 마을 |
| 반경 → 50km | 어둠 원 확대, 불빛 꺼짐, 불 꺼진 마을 수 증가 |
| 50km | 오른쪽에 "2014년, 이 병원 한 곳이 해낸 일" 22,000+ · 5,900+ 취소선 → "병원의 파괴는 … **지역 전체의 생존 기반**을 무너뜨립니다" |
| 결말 (스크롤) | 금빛 동전이 빛나며 "우리가 보낸 **1만 원의 온기**가 전장의 표적이 되지 않도록" + 서명 버튼 |
