| step | 진행률 | 상태 | 화면 변화 |
| --- | --- | --- | --- |
| 0 | 0 – 0.2 | 전장 | "국제법이 약속한 최후의 안전지대", 도시가 불타고 연기가 오른다 |
| 1 | 0.2 – 0.45 | 보호 구역 | 적십자에서 빛이 내려오고, 바닥에 "보호 구역" 점선 타원이 그려진다 (stroke-dashoffset) |
| 2 | 0.45 – 0.7 | 약속 | "병원은 어떤 상황에서도 **공격 대상이 아니다**", 창문 · 문에 불이 켜지고 사람 실루엣 |
| 3 | 0.7 – 1 | 협약 | 화면이 어두워지고 협약 종이가 위에서 떨어지듯 붙는다 → "이 약속은 현실에서도 지켜지고 있을까요?" |

모션: canvas 불씨(위로 떠오르는 주황 입자), 연기 기둥 CSS 흔들림, 불꽃 깜빡임, 점선 타원 그리기, 종이 낙하(회전 → 0도, 그림자).
