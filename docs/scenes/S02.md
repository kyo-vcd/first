## 상태 변화

| step | 진행률 | 상태 | 사용자 행동 → 화면 변화 |
| --- | --- | --- | --- |
| 0 | 0 – 0.18 | 질문 | "이 8,600원은 현장에서 무엇이 될까요?" + 버튼 + 86% 수조의 동전 더미 |
| (클릭) | 언제든 | 변신 | **버튼 클릭** → 동전이 위로 흩어지며 빛나고, 그 자리에서 물품 5종이 튀어나와 자리를 잡는다 (1.4초) |
| 1 | 0.18 – 0.45 | 물품 | 버튼을 누르지 않고 스크롤하면 자동으로 변신. 물품이 천천히 떠 있는 모션 |
| 2 | 0.45 – 0.72 | 담기 | 상자 앞판이 아래에서 올라오고 물품이 상자 안으로 모인다 |
| 3 | 0.72 – 1 | 질문 | 제목이 "그렇다면 이 물품들이 모인 **전장의 병원**은 안전할까요?"로 교체 |

## 모션
- 변신: 동전 canvas 파티클(위로 흩어짐 + 금빛 반짝임) → 물품이 scale 0 → 1, 약간 회전하며 안착 (`cubic-bezier` 튕김)
- 대기: 물품마다 다른 주기로 위아래 떠 있기, 주변에 금빛 먼지
- 담기: 물품이 상자 안쪽 좌표로 이동 + 작아짐, 상자는 아래에서 올라옴
