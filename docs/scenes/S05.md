# SCENE 05 — 보호 좌표 = 공습 좌표

시안: `docs/ref/design_v2.pdf` 17–20쪽 · 구현: `css/scenes/s05.css`, `js/scenes/s05.js` · 이미지: `images/s05/`

| 항목 | 내용 |
| --- | --- |
| 프로젝트 범위 | `.scene-05` 블록, `css/scenes/s05.css`, `js/scenes/s05.js` |
| 부모 영역 | `.scene-05` (320vh) › `.sticky-screen` |
| 변경 요소 | `.s05-map`(도시 항공 지도), `.s05-toggle`(공식 보호 좌표 / 실제 공습 타깃 버튼 2개), `.s05-pin`(병원 핀), `.s05-zone`(초록 보호 원), `.s05-scope`(붉은 조준경 · 모서리 프레임), `.s05-panel`(좌표 패널), `.s05-stat`(81% 패널) |
| 실행 조건 | **클릭**: 두 버튼으로 같은 지도를 두 시점으로 전환 (class12 연도 A/B 예제와 같은 구조). 스크롤 단계: 0 초록 보호 → 1 조준경 → 2 "보호 좌표 = 공습 좌표" → 3 81% |
| 유지 · 검증 | 스크롤 단계가 바뀌면 버튼 상태도 맞춰 바뀌고, 사용자가 버튼을 누르면 그 시점으로 즉시 전환 |

| step | 진행률 | 화면 변화 |
| --- | --- | --- |
| 0 | 0 – 0.22 | "병원은 공격을 피하려고 **위치를 미리 알립니다**", 초록 핀 · 보호 원 · 좌표 패널 |
| 1 | 0.22 – 0.48 | "같은 좌표를 **군의 조준경**으로 보면", 화면이 붉게, 조준경이 핀으로 다가와 LOCKING |
| 2 | 0.48 – 0.74 | "보호 좌표 **=** 공습 좌표", 두 좌표 일치 100% 표시 |
| 3 | 0.74 – 1 | 오른쪽 패널: **81%** 카운트업, 막대, "쿤두즈 외상센터, 2015년 10월 3일 →" (누르면 S06으로 스크롤) |

모션: 보호 원 맥동, 조준경 이동 · 회전 · 잠금 깜빡임, 모서리 프레임 조여짐, 숫자 카운트업, 스캔 라인.
