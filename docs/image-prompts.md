# ChatGPT 이미지 생성 프롬프트 (SCENE 01 소스)

> 생성 완료: 원본은 `docs/ref/images/assets/`, 사이트에 쓰는 가공본은 `public/img/` (연결 위치는 `docs/scenes/S01.md` 비주얼 표).
> 배경 · 바닥 · 동전은 이후 Codex CLI로 시안에 더 가깝게 다시 만들었다: `docs/ref/images/assets/codex/prompts.sh`.

시안(첨부 이미지 4장)과 같은 느낌의 **소스 이미지**를 ChatGPT로 만든다.
완성 화면이 아니라 재료를 따로 만들어야 웹에서 움직임·반응형을 유지할 수 있다.

## 사용 방법

1. ChatGPT 새 대화에 **시안 이미지 4장을 먼저 첨부**하고 아래 "공통 스타일"을 보낸다.
2. 같은 대화에서 에셋 프롬프트를 **하나씩** 보낸다 (한 번에 여러 개 요청하면 스타일이 흐트러진다).
3. 결과가 마음에 들 때까지 "같은 스타일로 다시" 를 요청하고, 고른 것만 저장한다.
4. 파일 이름은 표의 이름대로 저장해 이 대화에 첨부하거나 `docs/ref/assets/`에 올린다. 잘라내기·배치·연결은 Claude가 한다.

| 파일 이름 | 내용 | 크기 · 배경 |
| --- | --- | --- |
| `coin-gold.png` | 금화 4종 (2×2) | 1024×1024, 투명 |
| `coin-blood.png` | 핏자국 금화 4종 (2×2) | 1024×1024, 투명 |
| `bg.png` | 배경 질감 | 1536×1024, 불투명 |
| `floor.png` | 붉은 바닥 + 철조망 띠 | 1536×1024, 투명 |
| `stamp.png` | 후원하기 버튼 바탕 (찢긴 붉은 종이) | 1536×1024, 투명 |
| `thumb.png` | 슬라이더 손잡이 (핏방울) | 1024×1024, 투명 |
| `drips.png` | 흘러내린 핏물 자국 6종 | 1536×1024, 투명 |

수조 선, 슬라이더 선, 글자는 화면 크기에 맞춰 늘어나야 하므로 코드로 그린다 (이미지로 만들지 않는다).

## 공통 스타일 (처음에 1번)

```
첨부한 4장은 내가 만든 웹 인터랙티브 페이지 시안이야. 이 시안과 완전히 같은 질감·색감으로
웹에 쓸 "소스 이미지"를 하나씩 만들어 줄 거야. 앞으로 요청하는 모든 이미지에 아래 스타일을 똑같이 지켜 줘.

스타일
- 전쟁·의료 구호 캠페인의 어둡고 묵직한 분위기, 거친 실크스크린/리소 인쇄 질감
- 촘촘한 검은 점(하프톤 노이즈)이 모든 면 위에 고르게 찍혀 있음
- 색: 배경 #16110F(탄 종이 같은 검정), 낡은 금 #C99630(밝은 곳 #E3B555, 어두운 테두리 #9A6A1B),
  피 빨강 #E5262B, 크림 #EFE6D6
- 평면적인 일러스트, 사진처럼 보이지 않게, 3D 렌더 금지, 광택·반사광 금지
- 글자·워터마크·로고 넣지 않기
- 정면에서 본 모습(원근 없음), 그림자는 아주 약하게만

대답은 이미지로만 해 줘. 준비됐으면 "준비됨"이라고만 답해.
```

## 1. 금화 — `coin-gold.png`

```
시안 속 동전과 똑같은 금화 4개를 2×2 격자로 그려 줘.
- 1024×1024, 배경은 완전히 투명(PNG)
- 각 칸 가운데에 동전 1개, 동전 지름은 칸의 80%, 동전끼리 겹치지 않게
- 정면에서 본 원형 동전: 바깥 테두리 띠, 안쪽에 얇은 원형 홈, 가운데에 희미하게 닳은 문양
- 4개는 모양·크기·색이 같고, 가운데 문양과 점 질감만 조금씩 다르게
- 낡은 금색 #C99630, 테두리는 조금 어두운 #9A6A1B, 표면 전체에 촘촘한 검은 점
- 동전 둘레에 아주 얇은 어두운 갈색 테두리 그림자
- 핏자국 없이 깨끗한 금화
```

## 2. 핏자국 금화 — `coin-blood.png`

```
방금 만든 금화와 완전히 같은 동전 4개를 2×2 격자로 다시 그리되, 각 동전에 시안처럼 작은 핏자국을 넣어 줘.
- 1024×1024, 투명 배경, 칸 배치와 동전 크기는 이전 이미지와 동일
- 핏자국: 피 빨강 #E5262B, 동전 지름의 20~30% 크기, 번진 방울 + 작은 튄 자국
- 핏자국 위치는 4개 모두 다르게 (가운데, 왼쪽 위, 오른쪽 아래, 테두리 근처)
- 핏자국에도 검은 점 질감이 똑같이 찍혀 있어야 함
```

## 3. 배경 — `bg.png`

```
시안의 배경만 따로 그려 줘. 글자·동전·붉은 선·바닥은 모두 빼고 바탕 질감만.
- 1536×1024, 불투명
- 탄 종이 같은 아주 어두운 검정 #16110F, 가운데가 아주 조금 더 밝고 가장자리는 더 어둡게
- 고운 종이 입자, 가늘고 희미한 흰 긁힌 자국 20개 정도가 여기저기 사선으로
- 위쪽 20% 영역에만 아주 희미한 물방울 모양 패턴이 반복
- 아래쪽은 아무것도 없이 어둡게 (붉은 바닥은 따로 만듦)
- 전체가 어둡고 차분해서 위에 흰 글자와 금색 동전을 올려도 잘 보이게
```

## 4. 붉은 바닥 + 철조망 — `floor.png`

```
시안 맨 아래의 붉은 바닥과 철조망만 따로 그려 줘.
- 1536×1024, 투명 배경
- 이미지 아래쪽 25%에만 그림, 위쪽 75%는 완전히 투명
- 붉은 바닥: 아래로 갈수록 진한 피 빨강(#8C1613 → #6E110F), 위쪽 끝은 투명하게 부드럽게 사라짐
- 바닥 위에 아주 거친 붉은 점 노이즈
- 바닥 윗부분을 가로지르는 어두운 철조망 한 줄 (가는 철사 2가닥이 꼬여 있고 일정 간격으로 가시)
- 왼쪽 끝과 오른쪽 끝이 자연스럽게 이어지도록 (가로로 반복해 붙일 수 있게)
```

## 5. 후원하기 버튼 바탕 — `stamp.png`

```
시안의 "후원하기" 버튼 바탕만 그려 줘. 글자는 넣지 마.
- 1536×1024, 투명 배경, 가운데에 가로로 긴 직사각형 1개 (가로:세로 = 3.4:1, 이미지 가로의 70%)
- 피 빨강 #E5262B 종이를 손으로 거칠게 찢은 듯한 불규칙한 가장자리
- 아주 살짝 기울어짐(약 -1도)
- 표면에 촘촘한 어두운 점 질감, 가장자리는 조금 더 거칠게
```

## 6. 슬라이더 손잡이 — `thumb.png`

```
시안의 슬라이더 손잡이(핏방울 모양)만 그려 줘.
- 1024×1024, 투명 배경, 가운데에 1개, 이미지의 60% 크기
- 피 빨강 #E5262B의 둥근 핏방울, 가장자리가 조금 울퉁불퉁하고 아래쪽에 짧게 흘러내린 자국 1개
- 표면에 촘촘한 어두운 점 질감
```

## 7. 흘러내린 핏물 자국 — `drips.png`

```
시안의 수조 바닥 선에서 흘러내린 핏물 자국만 6개 그려 줘.
- 1536×1024, 투명 배경, 가로로 6개를 간격을 두고 나란히
- 각 자국: 위쪽은 폭 6px 정도의 짧은 세로 줄, 아래 끝은 둥근 방울
- 길이는 서로 다르게 (짧은 것부터 긴 것까지), 가장 긴 것은 이미지 높이의 40%
- 피 빨강 #E5262B, 가장자리는 손으로 그린 듯 조금 흔들리게, 점 질감
- 위쪽 끝은 수평으로 잘린 모양 (선에 붙일 것이므로)
```

## 결과가 시안과 다를 때 보낼 문장

- 너무 반짝이거나 3D 같을 때: `광택과 입체감을 빼고, 평면 인쇄물처럼 다시. 검은 점 질감을 더 촘촘하게.`
- 색이 너무 밝을 때: `전체를 시안처럼 더 어둡고 탁하게. 금색은 #C99630 기준.`
- 배경이 투명하지 않을 때: `배경을 완전히 투명한 PNG로 다시 만들어 줘. 체크무늬를 그리지 말고 실제 투명으로.`
- 동전 4개가 서로 달라 보일 때: `4개의 크기·테두리·색을 완전히 같게 맞추고 가운데 문양만 다르게.`
